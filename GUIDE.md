# NEON RIFT 2.0.1: review guide

1. Extract the whole ZIP. Open neon-rift/index.html in a desktop browser. No installation or server is required for desktop play. On phones use static hosting; local file opening may not work.
2. Move with WASD/arrows, aim with mouse, hold click to shoot. Space dashes. E/Shift uses an equipped ability. P/Esc pauses. Touch has independent stick, aim/fire, dash and ability controls.
3. Collect XP diamonds and choose one of three upgrades. Weapon upgrades build toward level 5; a matching catalyst makes an evolved weapon eligible in subsequent offers.
4. Survive the boss every fifth wave. Earn local Rift Shards, then visit Loadout / Armory > Core Matrix to buy permanent ranks. The next node in each branch needs one rank in its predecessor. Respec gives back purchase costs.
5. Elite Radar changes affix chance by +15% relatively per rank and gives +1 shard per rank per elite kill. Existing alive-elite limits still apply.
6. Settings includes touch aim-assist and Save Data Backup & Restore. Export copies/downloads text; import checks corruption and replaces progress. Keep a backup before restoring. Saves are local, not cloud-synced.
7. This is a review ZIP, not a live deployment. See README, docs/QA.md and CHANGELOG for current features, tests and remaining limits. The historical PDF guide describes the earlier release only.
